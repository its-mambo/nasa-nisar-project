# Portable judging sample

Run `python launch.py --mode sample` from the repository root after installing
`requirements-sample.txt`. The saved bundle is included under `judges/`;
neither the source `.h5` files nor the model weights are needed for playback.
`judges/current.json` selects the active immutable bundle. Keep the entire
selected directory, including `manifest.json`, `result.json`, and every PNG,
when distributing the project to judges.

The included sample was generated by real CPU inference on the two GCOV files
named in its manifest, originally in `src/`. The T0 pixel box is
`[5323, 2414, 11255, 6066]`, threshold `0.10`, and map reference `EPSG:32640`.
It has 5,932 × 3,652 native pixels and a projected rectangle of 8,665.4656 km².
The detector flagged 999,843 of 21,099,696 jointly valid model cells,
corresponding to 399.9372 km² at the 20 m analysis spacing. These are detector
flags, not confirmed environmental changes.

The bundle preserves full-resolution PNGs and is approximately 356 MiB on disk.
Playback streams files; it does not load that entire bundle into Python memory.
A local startup check measured about 40 MiB for the Python server, excluding
the browser, which decodes images separately.

Qwen completed generation but omitted the required hypothesis uncertainty
field. The current sample displays its actual saved sentences as an unverified
plain-text explanation, including its observation, possible explanation, and
suggested checks. It does not fill in missing claims or pretend the structured
output passed validation. Physical attribution remains unresolved.

The original raw model response remains unchanged in `result.json` and the
app's technical details. The original immutable bundle is retained for audit;
`current.json` points at the revised presentation. Recreate this presentation
with `python cache_sample.py --refresh-report`; no model run or HDF5 input is
needed. Restart the sample server after changing the active revision.

The manifest records acquisition metadata, input file sizes and SHA-256 hashes,
generation time, ROI, threshold, detector identifier, and artifact checksums.
Startup verifies the cached artifacts. Run `python cache_sample.py --refresh`
on a capable machine with the source pair and weights to generate another
bundle; previous bundles remain on disk.
